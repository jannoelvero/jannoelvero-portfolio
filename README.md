# Dr. Jan Noel Vero | Professional Portfolio

My personal professional portfolio website showcasing my work and experience across hospitality and tourism, business and data analytics, higher education, research, sales, partnerships, and strategic leadership.

## Live Portfolio

**Website:** https://jannoelvero.netlify.app

## About This Project

I developed this website as both my professional portfolio and a practical web development project.

The portfolio brings together my multidisciplinary professional background and provides a central platform for employers, hospitality and tourism professionals, academic institutions, researchers, collaborators, and potential clients to explore my experience and work.

## Portfolio Assistant

The website includes a custom JavaScript portfolio assistant.

Visitors can ask questions about verified information presented in my portfolio, including professional experience, hospitality expertise, analytics projects, academic experience, research, education, qualifications, certifications, and skills.

When the requested information is not available, the assistant directs the visitor to the Professional Inquiry form rather than generating an unsupported answer.
